# Tasks-CLI

## Step 1

Make sure node is installed on the system. Use the command "node --version" to
see if it is already installed, if not, go to offical nodejs website and install
it.

## Step 2

Make sure npm is also installed while you installed node. Confirm with command
"npm --version".

## Step 3

Run the command "npm install" to install all dependencies of the project.

## Step 4

Run the command "npm run build" to generate the dist folder.
